BlockShareDistributed File Storage

Files split into chunks, spread across a cluster — and trust you can verify.

Who owns a file and who can open it is decided either by the Django server or by Ethereum smart contracts — the administrator can switch between the two at runtime.

  • Chunked, replicated storage over a custom TCP protocol
  • Optional on-chain ownership, sharing and versions
  • Merkle-root integrity checks with self-repair
