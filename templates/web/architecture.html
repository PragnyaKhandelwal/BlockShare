Architecture

A modular distributed file-sharing system with switchable centralized (Django) or decentralized (smart contract) coordination.

Upload (Blockchain ON)

sequenceDiagram
  participant U as Alice
  participant D as Django
  participant N1 as Node A
  participant N2 as Node B
  participant SC as FileRegistry
  U->>D: POST /upload (multipart)
  D->>D: split into chunks, SHA-256 each
  D->>N1: BSP PUT chunk (forward to B)
  N1->>N2: BSP PUT chunk
  N2-->>N1: OK stored_on=[B]
  N1-->>D: OK stored_on=[A,B]
  D->>D: Merkle root + manifest
  D->>SC: registerFile(id, root, manifest) signed by Alice
  SC-->>D: FileRegistered event
  D-->>U: 201 Created

Shared download (Blockchain ON)

sequenceDiagram
  participant B as Bob
  participant D as Django
  participant FS as FileSharing
  participant FR as FileRegistry
  participant N as Nodes
  B->>D: GET /files/F001/download
  D->>FS: checkPermission(F001, Bob)
  FS-->>D: READ
  D->>FR: getVersion(F001, v)
  FR-->>D: merkleRoot
  D->>D: manifest root == on-chain root?
  D->>N: parallel BSP GET chunks (failover + read repair)
  N-->>D: chunks (SHA-256 verified)
  D-->>B: streamed file
