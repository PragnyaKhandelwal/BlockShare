What happens when you upload

  1. The file is split into {{ system.chunk_size|filesizeformat }} chunks.
  2. Each chunk is hashed with SHA-256 — the hash is its address on the storage nodes (identical chunks are stored once: deduplication).
  3. A consistent-hashing ring picks {{ system.replication_factor }} node(s) per chunk.
  4. The chunk is sent over TCP (BSP/1 protocol) to the first node, which forwards it to the next replica (replication pipeline).
  5. The chunk hashes form a Merkle tree; its root identifies this exact version.
  6. A manifest (chunk list + locations) is stored on the nodes as well.

  7. Your wallet signs FileRegistry.registerFile() — the smart contract records you as owner together with the Merkle root.
